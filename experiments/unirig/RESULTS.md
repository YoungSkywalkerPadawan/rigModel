# UniRig 首轮实验记录

## 2026-09-17：CPU 准备

**目的**：为用户确认的 25 个持续旋转物体准备 UniRig 骨架候选推理，之后与 65 根已有机械参考轴比较位置。

**条件**：官方 UniRig 源码 `6793c6640ff01c8fb389f3993434124bb43d2933`；公开 Articulation-XL2.0 骨架权重 revision `36842e2b5947e9e60f89275b83208c8e74071c63`。AutoDL 当前 CPU 模式、0.5 核、2 GiB 内存。无训练，无 GPU 推理。

**结果**：1,439,617,174 字节骨架 checkpoint 及 644 字节 OPT config 均通过官方文件标识校验。25 个输入全部完成，每例 65,536 点，合计 1,638,400 点；源几何/标注与冻结基准逐例核对。585 个权重张量键与形状严格匹配，网络参数量 360,130,048。CPU 预检返回 `READY_FOR_GPU`，`gpu_available=false`、`gpu_inference_run=false`。

**结论**：依赖、权重、输入和 CPU 可验证的网络结构均已准备好，可以通知用户开启 GPU。尚未产生模型候选或准确率，不能将 CPU 准备称为推理成功。

**局限**：CPU 内存有限，完整模型加载与 CUDA 前向留到用户开启 GPU 后。已知参考为几何整理标注；尚未证明绑骨位置适合机械轴心。

准备时补装匹配 PyTorch 2.4 / CUDA 12.4 的 torch-cluster。最初继承旧环境时出现旧 UniPhysGen 应用的 Transformers 固定版本冲突；将新环境共享依赖与旧应用隔离后 `pip check` 通过，旧环境未修改。

权重全量哈希读取留下约 1.44 GB 文件缓存，曾导致 CPU 模式导入 PyTorch 的进程被终止。只对已验证权重使用 `posix_fadvise(DONTNEED)` 释放其干净文件缓存后，实例内存计数降至约 476 MB；PyTorch 单独导入峰值 RSS 376,468 KiB，随后完整预检通过。没有修改模型文件或放宽实例资源限制。Open3D 仅用于可选导出，本适配使用 trimesh，因此不安装到骨架运行环境。

离线契约验证覆盖坐标还原、沿轴平移不变性、骨架拓扑拒绝，以及失败/缺失候选保留分母。GPU 模型实际输出、速度、显存峰值与候选覆盖率均等待本轮开卡后记录。

## 2026-09-17：GPU 推理与位置评估

**目的**：检验上述预训练 UniRig 的关节点集合，能否为 25 个既有持续旋转物体提供准确的机械轴位置候选。用户开启 GPU 后，先运行地球仪单例，再运行完整 25 例；未训练模型，未调整参数挑选结果。

**条件**：沿用 CPU 准备时冻结的源码、权重和输入。RTX 4090 24 GiB，PyTorch 2.4.1+cu124、Transformers 4.51.3、FlashAttention 2.7.3。FP32 权重、BF16 autocast，15 beams、top-k 5、top-p 0.95、temperature 1.5、repetition penalty 3、max-new-tokens 2048；每例 seed 12345。完整版本和参数见归档的 `setup/environment.freeze.txt`、`results/run_config.json`。完整装配保留原姿态、Z-up 数值世界坐标，不做网格简化；每例实际使用已准备的 65,536 点。

**结果**：25/25 物体均成功生成并导出，65/65 根轴全部计分，无运行失败和显存溢出。共产生 296 个节点，单例 3–45 个。各例计时之和 31.67 秒、中位数 1.03 秒；计时含每例输入传输、生成和导出，不含首次模型加载，因此不是完整任务墙钟时间。PyTorch `max_memory_allocated` 峰值 3.903 GiB，不代表进程全部 GPU 占用。

固定参考轴方向，只评估位置；误差为节点到参考轴线的垂距除以冻结的子件尺度：

| 位置来源 | 误差 ≤ 1% | 误差 ≤ 2% | 误差中位数 / 子件尺度 |
| --- | ---: | ---: | ---: |
| UniRig 每轴最佳节点（参考标签选取，oracle） | 7/65（10.77%） | 13/65（20.00%） | 32.77% |
| 旧基准冻结的子件中心 | 39/65（60.00%） | 49/65（75.38%） | 0.63% |
| 旧 generic_v29 的位置锚点 | 56/65（86.15%） | 63/65（96.92%） | 0.18% |

v29 取自旧评估 `runs/cpu_v1/generic_v29/records/`。先将其 pivot 沿自身预测轴平移到最接近冻结子件中心的等价锚点，再计算该点到参考轴的垂距。三列使用同一参考方向比较位置；这不是原先“方向和位置同时通过”的综合指标。UniRig 用真值选择节点，属于这组离散节点在该位置指标下的上限，不能当成自动预测准确率。

UniRig 达到 1% 的 7 根轴：风车 `rotor_spin`、办公椅 `seat_swivel`、望远镜 `azimuth_spin`、赛车两个前轮、永动仪 `orbit_spin`、旋转切割台 `table_spin`。它们全部已被 v29 命中，新增覆盖为 0/65。

**结论**：本批资产上，当前预训练 UniRig 的离散节点作为机械轴心候选明显弱于已有几何方案；即使使用参考标签选择节点，也不能补足 v29 的失败轴。因此本轮证据不支持用该配置直接替换已有原点方案。这里评估的是节点集合，未验证骨段插值、局部几何精修、微调或其他绑骨模型；后续研究方向尚未决定。
